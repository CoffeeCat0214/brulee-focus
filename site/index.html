V2 Gentle Gatekeeper

Coffee's gone. Tiny break.

CoffeeCat V2 turns the end of a focus session into a shareable, humane interruption. Wherever you are browsing, the page fills with semi-transparent coffee, CoffeeCat steps in, and a five-minute break begins.

Coffee flood break The feed stays visible, but the coffee takes over.

Focus Coffee

The cup mirrors your timer and drains smoothly several times per second, so time passing is visible without needing a loud alarm.

Any page

CoffeeCat follows the timer instead of a site list. When Focus Coffee ends, the current page becomes the break surface.

Local by default

No backend, analytics, account, or social login. Settings and focus stats stay in Chrome extension storage.

Install locally

  1. Open chrome://extensions.
  2. Turn on Developer mode.
  3. Choose Load unpacked.
  4. Select the CoffeeCat folder.
  5. Visit a normal web page and start Focus Coffee.
